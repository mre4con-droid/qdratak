# أدوات مسار التحصيلي

مسار التحصيلي تحت `/tahsili/` **مولَّد** من المحتوى في `content/tahsili/` — لا يُعدَّل
ملف HTML فيه يدويًا، فأي تعديل يُفقد عند إعادة البناء.

## البناء

```bash
python3 tools/build_all.py     # بناء كل شيء
python3 tools/check_pages.py   # فحص الصفحات في متصفح حقيقي
```

## لماذا مولَّد؟

صفحات القدرات هي **المصدر الوحيد للحقيقة في الشكل**: `tools/chrome.py` يستخرج منها
الأنماط والترويسة ووحدة المساعد الذكي، فتبقى صفحات التحصيلي مطابقة لها تلقائيًا،
وأي تغيير في شكل القدرات ينعكس على التحصيلي بإعادة بناء واحدة.

## الملفات

| الملف | الدور |
|---|---|
| `chrome.py` | استخراج القطع المشتركة من صفحات القدرات |
| `build_tahsili.py` | توليد صفحات الدورات من ملفات المواد |
| `build_simulator.py` | توليد محاكي الاختبار لكل مسار |
| `build_pages.py` | توليد الصفحة الرئيسية وبنك الأسئلة |
| `link_tahsili.py` | ربط المسار من `index.html` و`sitemap.xml` (غير تراكمي) |
| `authoring.py` | مساعدات كتابة المحتوى |
| `check_pages.py` | فحص الصفحات في Chromium: أخطاء JS والعرض والتحقق |

## المحتوى

`content/tahsili/blueprint.json` يحدد هيكل الاختبار — المواد وعدد أسئلة كل مادة
والمدة. **توزيع المواد فيه مبدئي ولم يُؤكَّد من مصدر رسمي**؛ عند اعتماد التوزيع
الرسمي يُعدَّل هذا الملف وحده ثم يُعاد البناء.

`content/tahsili/<track>/<subject>.json` يحمل لكل مادة:

```jsonc
{
  "id": "biology", "name": "الأحياء", "title": "...", "intro": "...", "about": "...", "tip": "...",
  "branches": [{ "id": "cell", "name": "...", "learn": "...", "forms": [], "steps": [],
                 "example": { "question": "...", "think": "...", "options": [] },
                 "summary": "...", "note": "..." }],
  "questions": [{ "stem": "...", "options": ["...", "...", "...", "..."], "correct": 0,
                  "explanation": "...", "difficulty": 1, "branch": "..." }]
}
```

### إضافة أسئلة

اكتب السؤال والإجابة الصحيحة أولًا في `options` مع `correct: 0` — البناء يخلط
الخيارات خلطًا حتميًا مشتقًا من نص السؤال، فلا يظهر نمط يكشف الإجابة، ويبقى
الترتيب ثابتًا بين عمليات البناء.

احرص أن يبلغ بنك كل مادة حصتها في `blueprint.json` على الأقل، وإلا استكمل المحاكي
العدد من مواد أخرى وانحرف التوزيع عن المخطط.
